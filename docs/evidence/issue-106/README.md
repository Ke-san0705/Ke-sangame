# Issue #106 刹那の一閃

Chromium でモード選択から「刹那」「START」と進んで撮影した。PC は 1280 × 830、スマートフォンはタッチ入力を有効にした 390 × 844。画面の切り替わりを同じ条件で再現できるよう、出題用の乱数とブラウザーの時計を固定して撮影した。

| 条件 | 証拠 |
| --- | --- |
| PC・数字キーで正答 | [待機](desktop-waiting.jpg) · [合図と問題](desktop-cue.jpg) · [主人公の一閃](desktop-slash.jpg) · [スキップ後の勝利](desktop-result.jpg) |
| スマートフォン・テンキーで誤答 | [待機](mobile-waiting.jpg) · [敵剣士の一閃](mobile-slash.jpg) · [スキップ後の敗北](mobile-result.jpg) |

- 合図直前には合図も問題も表示されず、表示時刻に両方が現れることを Chromium で確認。問題パネルの位置と寸法は待機中と合図時で一致した。
- PC では Esc、タッチ環境では「演出をスキップ」で決着を短縮した。次の相手・再戦の開始後は「合図を待て」と表示され、お手つき表示は出なかった。
- PC で合図から 140 ms 後に回答すると、反応時間は表示直後もスキップ後も 0.140 秒だった。自動テストでは 800 ms の演出終了時も確定済みの反応時間が同じ値であることを確認した。
- 自動テストで CPU 勝利・誤答・お手つき敗北のすべてに敵剣士の一閃が割り当てられることを確認した。Chromium のモーション抑制設定では、お手つき敗北時に決着後の構図を直接表示した。
