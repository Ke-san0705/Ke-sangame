# Issue #107 刹那の無限勝ち抜き

Chromium で「刹那」から難易度を選び、実際に画面を操作して撮影した。出題用の乱数とブラウザーの時計は再現用に固定した。

| 環境 | 撮影した場面 |
| --- | --- |
| PC（1280 × 830、キーボード） | [難易度選択](desktop-difficulty.jpg) · [決着後に一時停止](desktop-paused.jpg) · [6人抜き後の第7戦](desktop-round-seven.jpg) |
| スマホ相当（390 × 844、タッチ） | [上級の第3戦で「10」を入力](mobile-two-digit.jpg) · [CPU先制後の戦績](mobile-result.jpg) |

- PC では決着演出後に対戦間を一時停止し、再開後に自動進行することを確認した。6人抜き後の第7戦で CPU に先制され、ページ再読み込み後も6人の記録を確認した。
- スマホ相当では画面テンキーで2桁を入力し、Enter で勝利した。次戦は無入力のまま CPU に先制され、ページ再読み込み後も3人の記録を確認した。
- 自動テストでは合図直前・合図と同時・CPU と同時の境界、誤答、お手つき、CPU の反応時間の下限、次戦への入力持ち越し防止、旧記録の読み込みを確認した。
