# 演出タイムライン（DEV-01）

| パッケージ | 固定バージョン | 配布パッケージのライセンス表記 |
| --- | --- | --- |
| `gsap` | 3.15.1 | Standard “no charge” license |
| `@gsap/react` | 2.1.2 | SEE LICENSE AT https://gsap.com/standard-license |

両パッケージとも配布メタデータは [GSAP Standard License](https://gsap.com/standard-license/) を参照する。バージョンと配布物の整合性ハッシュはルートの `package-lock.json` に記録した。

`useEffectTimeline` は演出を所有する画面から、DOM スコープ、有効条件、演出のトリガー、低負荷モードの値を受け取る。画面のアンマウント、画面内のフェーズ切り替え、トリガー更新、演出抑制への切り替えで GSAP コンテキストを revert し、タイムラインと適用したスタイルを破棄・復元する。

`prefers-reduced-motion: reduce`、低速更新ディスプレイを示す `update: slow`、または呼び出し元の `lowPower` が有効なら GSAP 演出を抑制する。討伐の正解時は、共通の `BattleStage` 内で振動・ズームを行う。解放ゲージのような入力判定に必要な表示は従来の時計で進む。

画面遷移、ゲーム状態、締切、入力判定は React と既存のタイマー・イベント時刻で管理する。タイムラインは描画専用とし、演出の完了を待って状態を進める処理は置かない。

描画比較の手順と結果は [検証ページの README](../benchmarks/rendering/README.md) を参照。

## 戦闘カメラ（DEV-02）

カメラが動かすのは 16:9 の戦闘領域の中だけ。描画順は遠景、地面・近景、後景エフェクト、キャラクター、前景エフェクト。HUD・計算式・入力欄・テンキーはカメラの外に配置する。振動の幅、ズーム倍率、コンボの表示時間は `src/lib/battleUi.ts` で設定する。

解放の準備・入力中も演出を 16:9 の領域に収める。確定後の最終必殺技は画面全体を使う。

## 通常攻撃・連撃（DEV-07）

討伐モードの正解時は DEV-06 の `ATTACK_STAGES` に対応する攻撃を再生する。`attackEffects.ts` に色・時間・移動量・カメラの引き・VFX 上限を置く。クリティカルと被弾には短い振動、進化には短いズームを使う。既存のチャージ色と正解数に応じて侍のオーラが強まる。

既定は連撃合成（`overlap: 'compose'`）で、VFX は最大3件。設定を `'replace'` にすると最新の1件で上書きする。低負荷モードとモーション抑制時は最新の簡易 VFX だけを描画し、カメラ・キャラの動作・発光・粒子を抑える。効果音は攻撃用の同時発音数に上限を設ける。

スプライトは JSON の攻撃クリップを参照し、キーが未定義なら通常攻撃を使う。通常攻撃もなければセルの切り替えを省く。GSAP の完了処理は描画済み VFX の片付けに使う。討伐・HP・得点・入力と計時は既存の戦闘処理で進む。

## 刹那の一閃（DEV-10）

夕暮れの平原で侍と敵剣士が向き合う。決着の 800 ms は踏み込み 80 ms、一閃 120 ms、ヒットストップ 50 ms、静寂 200 ms、倒れ込みと納刀 350 ms。各区間とカメラ、移動の調整値は `src/lib/setsunaConfig.ts` に置く。ヒットストップ後、勝者の移動をゆっくり収めてから敗者を倒す。

反応時間の起点は合図と問題を表示するタスクで記録し、回答イベントの時刻で勝敗と記録を確定する。演出タイムラインをスキップした場合や、モーションを抑制する環境では、倒れ込みと納刀を終えた構図を表示する。
