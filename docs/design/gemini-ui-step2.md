# 「計算無双」UIデザイン仕様書

## 1. 全体のデザインコンセプト
**「 Eスポーツのような緊張感と、アーケードゲームの爽快感が融合した、瞬時に没頭できるスタイリッシュUI 」**
学習アプリ特有の「お堅さ」を排除し、黒・紺をベースに蛍光カラーを効かせた「ネオ・アーケード」テイスト。思考を邪魔しない極限までシンプルなレイアウトでありながら、アクションに対する心地よいレスポンスで中毒性を生み出します。

## 3. 画面ごとの要素と配置（スマホ縦幅 390px 想定）

### ① トップ／モード選択画面

画面上部から下部へ流れるように設定を選択し、最下部の巨大なボタンでスタートする配置です。

#### 【配置と要素（上から順）】
1. **ヘッダー**
   - **見た目**: 「計算無双」の立体的なネオンロゴ（中央）。右上にトロフィーアイコン（「ランキング」ボタン）。
2. **演算選択（えんざん）**
   - **見た目**: 5列のグリッドボタン［ ＋ ｜ − ｜ × ｜ ÷ ｜ ミックス ］。選択中だけイエローの太枠＋発光。
3. **レベル選択（むずかしさ）**
   - **見た目**: 横スクロールまたは5段のタブ。
   - **文言例**:
     - `Lv.1 しょきゅう`（※選択時はアプリ全体の文言が「ひらがなモード」に切り替わる）
     - `Lv.2 ちゅうきゅう` / `Lv.3 じょうきゅう` / `Lv.4 超級` / `Lv.5 無双`
4. **制限時間選択（じかん）**
   - **見た目**: 3つのセグメントボタン［ 30秒 ｜ 60秒（標準） ｜ 120秒 ］。
5. **スタートエリア（画面最下部固定）**
   - **見た目**: 画面幅いっぱいの巨大なイエローボタン。グラデーションとアニメーションで主張。
   - **文言**: 「スタート！（たしざん / Lv.1 / 60びょう）」のように選択内容をボタン内に明記。

### ② ゲーム画面

画面上部に状況、中央に問題、下部にキーボードを配置した、親指だけで操作完結するレイアウトです。

#### 【配置と要素（上から順）】
1. **プログレス＆タイマーバー**
   - **見た目**: 画面最上部に横幅いっぱいのプログレスバー（時間が減ると緑→黄→赤に変化）。その直下に巨大なデジタルタイマー（例: `残り 45 秒`）。
2. **スコア＆コンボ表示（右上・左上）**
   - **見た目**: 左に「せいかい数: 12」、右に「コンボ: 5!」。
3. **問題表示エリア（メイン）**
   - **見た目**: ダークブルーのカードの中に、巨大で太いフォントで問題を表示。
   - **文言例**: `7 × 8 = ?`
4. **入力表示エリア**
   - **見た目**: 下線付きの入力枠。入力した数字がリアルタイムで大きく表示される。不正解時は枠が赤く揺れる。
5. **画面テンキー（スマホ時・画面下部半分を占有）**
   - **レイアウト（4x4グリッド）**:
     ```text
     [ 7 ] [ 8 ] [ 9 ] [ クリア ]
     [ 4 ] [ 5 ] [ 6 ] [  パス  ]
     [ 1 ] [ 2 ] [ 3 ] [        ]
     [    0    ] [ . ] [ けってい ]
     ```
   - **見た目**:
     - `0〜9`: タップしやすい立体的なグレーボタン。
     - `クリア`: オレンジ色。「一文字消す/全消し」。
     - `パス`: 控えめなダークグレー（押し間違い防止のため離す）。
     - `けってい`: 右下に縦長（または最下部横長）で配置された**最も大きいイエローボタン**。

### ③ 結果画面

ゲーム終了後、達成感を演出するリザルト画面です。

#### 【配置と要素（上から順）】
1. **リザルトヘッダー**
   - **見た目**: 「タイムアップ！」の文字のあと、バンとスタンプが押されるように**「ランク称号バッジ」**が大きく表示。
2. **スコア表示**
   - **見た目**: 一番目立つ巨大文字。「12,450 pt」。自己ベスト時は「NEW RECORD!」のキラキラ演出。
3. **詳細スタッツ（2×2のカード配置）**
   - **正解数**: `42 問`
   - **ミス数**: `2 回`
   - **正確率**: `95.5 %`
   - **平均回答速度**: `1.2 秒/問`
4. **オンラインランキング登録エリア**
   - **見た目**: 1行のテキスト入力 ＋ 登録ボタン（任意）。
   - **文言**: 「なまえを入力してランキングにちょうせん！」［ ニックネーム（最大8文字） ］［ とうろく ］
5. **アクションボタン（画面下部）**
   - **見た目**: 2つのボタンを上下に配置。
   - **メイン**: 「もう一度あそぶ」（イエロー・大）
   - **サブ**: 「モード選択にもどる」（枠線のみ・中）

## 4. ゲームらしさを出す演出アイデア（軽量実装）

Webブラウザで動作が重くならない、CSS/Web Audio API中心の軽量演出です。

*   **正解時（爽快感）**:
    *   入力枠が「ポンッ」と一瞬拡大（CSS scale）。
    *   画面全体の外周（枠線）が「ネオンミント」に一瞬ピカッと光る。
    *   高いピッチの「ピンポン！」という効果音（コンボが続くと音が徐々に高音に）。
*   **不正解時（ペナルティの明確化）**:
    *   問題枠が左右にブルッと震える（CSS Shakeアニメーション）。
    *   入力数字が赤くなり、一瞬で自動消去される。
    *   低い「ブッ」という効果音。
*   **残り時間わずか（ラスト10秒の緊張感）**:
    *   タイマーバーが赤く点滅。
    *   背景で心臓の鼓動のような「トックン…トックン…」という重低音（またはBGMのテンポアップ）。
*   **結果発表（達成感）**:
    *   スコアの数値が「0」から「12,450」までドラムロール音とともに高速でカウントアップ。
    *   称号バッジが「ドン！」と拡大して登場。

## 6. UI/UX上の注意点・配慮事項

1.  **低学年（小学生）への配慮（文言の動的切り替え）**
    *   モード選択で「Lv.1（またはLv.2）」を選んだ場合、アプリ全体のテキストを自動的に**「ひらがな中心」**に切り替えます（例：「正確率」→「せいかくさ」、「結果発表」→「けっか」）。
2.  **スマホでの押し間違い（誤タップ）防止**
    *   画面テンキーのキーサイズは最低でも `48×48px` 以上（推奨 `60px` 以上）を確保。
    *   誤操作で諦めてしまわないよう、**「パス」ボタンは「決定」や「数字」キーから少し離し**、色も主張しすぎないダークグレーにします。
3.  **キーボード入力と画面テンキーの共存（レスポンス確保）**
    *   **PC時**: テンキー入力はもちろん、`Enter`で決定、`BackSpace`でクリア、`Space`でパスに対応。
    *   **スマホ時**: スマホ標準のOSキーボード（iOS/Androidのキーボード）が立ち上がると画面が塞がってしまうため、`input`タグに `readonly` または `inputmode="none"` を指定し、**独自デザインのWEBテンキーのみで操作させる**ことで画面崩れを防ぎます。
4.  **決定ボタンの押しやすさ**
    *   テンキーの右下、または画面の一番下に「決定キー」を大きく配置し、右手・左手どちらの親指でも押しやすいように領域を広げます。
