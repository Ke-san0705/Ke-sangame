# STEP 0 確定仕様 ― 計算無双（2026-11-21確定）

コンセプト：誰でも簡単に使えて計算力が鍛えられるWebアプリ。寿司打のように気軽に遊べる。
アプリ名：**計算無双**／リポジトリ名：**Ke-sangame**

## 回答（片山さん、2026-11-21）

1. **対象ユーザー**：小学生・中高生
2. **計算の種類**：いくつか選べるようにする。当面は四則演算のみ、今後追加する。四則の中でもレベルを用意し、最大で4桁。分数・小数・負の数は高レベルに追加する
3. **ゲーム形式**：当面は制限時間制
4. **回答入力**：PCではキーボード、スマホなどでは画面にオリジナルテンキー
5. **レベル**：5段階。1＝小学校低学年、2＝小学校高学年、3＝中学生、4＝高校生、5＝とにかく難しく
6. **スコア**：スコア表示は欲しい。オンラインランキングも可能なら。ログインしなくても遊べるようにする
7. **デザイン**：シンプルで、少しゲームチックにしても良い
8. **デバイス**：スマホ＋PC両対応。将来的にスマホアプリ化できたらよい
9. **名前**：アプリ名「計算無双」、リポジトリ名「Ke-sangame」
