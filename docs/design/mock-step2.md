# UIモック ― STEP 2（2026-11-21）

- 正本：Figma「計算無双 UIモック」 https://www.figma.com/design/sFgfvaZbzcg05FTyVnbdSU
- 画面：1_トップ（node 1:2）／2_ゲーム（1:44）／3_結果（1:83）、いずれもスマホ縦 390×844
- 生成方法：Gemini API（gemini-3.5-flash）のUIデザイン案（gemini-ui-step2.md）をマルが取捨し、Figmaへ構築。構築スクリプトは figma-mock-step2.js
- 採用したデザイン：ダーク基調（背景 #0F172A、カード #1E293B）＋エレクトリックイエロー #FFC700、正解 #00E676、警告 #FF1744。トップは演算チップ／レベル5行／時間セグメント／選択内容入りの大きなスタートボタン。ゲームはタイマーバー＋問題カード＋4×4テンキー（けっていは右下に縦長の大ボタン、パスは控えめに配置）。結果はランク称号バッジ（例：閃光の計算将軍）、スコア、2×2スタッツ、ランキング登録欄、再戦／戻るボタン
- Gemini案から採用しなかったもの：コンボ表示（スコア設計にコンボがないため）、ニックネーム最大8文字（設計書v2の10文字を優先）
- 実装メモ：Lv.1/Lv.2選択時のひらがな文言切替、タイマーバーの色変化（緑→黄→赤）、正解・不正解の軽いアニメーションと効果音は、Gemini案の演出リストを実装時の参考にする
